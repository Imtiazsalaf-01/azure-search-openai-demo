This solution creates a ChatGPT-like frontend experience over your own documents using RAG (Retrieval Augmented Generation). It uses Azure OpenAI Service to access GPT models, and Azure AI Search for data indexing and retrieval.


<img width="468" height="698" alt="image" src="https://github.com/user-attachments/assets/81f64a36-bab4-493a-8915-82ba7a550865" />

This solution's backend is written in Python. There are also JavaScript, .NET, and Java samples based on this one. Learn more about developing AI apps using Azure AI Services.

The integration of Azure Cognitive Search and OpenAI models creates a robust and intelligent semantic search system. It allows users to interact with internal data in a conversational manner, significantly improving information discovery, accuracy, and usability across large-scale unstructured datasets.
